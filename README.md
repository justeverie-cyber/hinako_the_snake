# Hinako the Snake 🐍
This is my first project, hope you like it > &lt;

A terminal-based AI pet snake powered by a local language model.

## Features
---------
- Local LLM-powered snake companion
- Persistent memory
- Feeding system
- Hunger mechanics
- Energy system
- Rest and sleep actions
- ASCII wake-up animation
- Conversation history management
- Terminal-based interface

## A Little bit of Lore
------------------------
Basically I loved snakes as a kid, I had one but sadly had to sell him.
His name was Kevin and he was a Yellow Pied Python, my mom was afraid
of him which led me to sell him. But now? I'm much older, have another
chance of getting another snake. So I thought maybe I could make a 
digital version of a snake before having another named Hinako. I took
the name from a recent game called Silent Hill F, I do not claim to 
have the rights and is not affiliated with or endorsed by Konami or the creators.
I only used it to name my pet snake. All original rights to the name 
go to the creators of Silent Hill F. I made this to keep myself and you (yes 
you too User!!) company. You can even edit it from a snake to whatever
animal you want when you download the code! Enjoy and lots of love! ✝️


## Requirements

* Python 3
* llama-cpp-python
* A GGUF language model (any model your device can run)

## Run

python Hinako.py
